# Phase 2 Security Compliance Matrix

This is the point-in-time Phase 2 control inventory after Task 5. It references, but does
not reproduce, the external control catalogs pinned in [SPEC section 32](../SPEC.md#32-security-requirements).
`applicable` means the control remains in the Phase 2 release gate but is not yet claimed
complete. `implemented` means the cited automated evidence exists. Exceptions are limited
to surfaces intentionally absent from the approved Phase 2 design.
